# 淡路島旅行アプリ v37 AIプラン・地図即時反映・参考サイト導線・画面整理

## 今回直した内容

### 1. ヘッダーを本当に共通化

これまで各HTMLにヘッダーHTMLをコピーしていたため、
ページごとに差が出る可能性がありました。

v37では `_header.html` を1個だけ用意し、
全ページから `{% include '_header.html' %}` で読み込みます。

今後ヘッダーを変更するときは1ファイルだけ直せば全ページへ反映されます。

フッターも `_footer.html` に共通化しました。

### 2. `/ai-plan` と `/plan` の役割を分離

- `/ai-plan` = 条件を選んで旅行プランを自動作成するページ
- `/plan` = 作成済みプランを編集・並べ替え・地図確認するページ

`/plan` にあった重複した「おまかせプラン作成」ボタンは外し、
AIで新しく作りたい場合は `/ai-plan` へ移動する導線へ変更しました。

### 3. AIプラン作成後、地図へ自動反映

AIプラン作成後に `/plan?generated=ai` へ移動した場合、
位置情報がない登録スポットを自動で順番に検索します。

取得できたスポットから地図へ①②③…の順で反映します。

位置検索はOpenStreetMap / Nominatimを利用し、
既存のサーバー側1秒間隔制御・キャッシュ・回数制限を維持しています。

### 4. プランから参考サイトへ移動可能

旅行プランの各スポットカードに

`公式・参考サイトを見る ↗`

を追加しました。

`spots.csv` の `source_url` を利用するため、
AIが選んだスポットでも、そのまま施設公式サイト等の参考ページを開けます。
